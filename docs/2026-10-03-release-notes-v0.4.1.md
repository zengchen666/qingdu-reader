## 2. 为什么之前一句都召不回

`AskKeyword.of()` 只删疑问词，把剩下**整串**丢进 FTS5。而 FTS5 的 `MATCH` 是
**AND 语义**，配合 `CjkTokenizer` 的二字滑窗切分，N 个字的检索词会变成
N-1 个 bigram token —— 要求原文里**同时出现**这 N-1 个**相邻**二字对。

这等于要求原文里有这么一整句话：

```
问句苏沐橙喜欢谁
  -> token: 苏沐 沐橙 橙喜 喜欢 欢谁
            ^^^^     ^^^^
            「橙喜」「欢谁」这类跨词相邻对，正文里几乎不存在
```

真书实测（修复前）：

| 问句 | FTS5 token | 候选章 |
|---|---|---|
| 叶修 | `叶修` | 1523 ✅ |
| 叶修是谁 | `叶修` | 1523 ✅ |
| 苏沐橙喜欢谁 | `苏沐 沐橙 橙喜 喜欢 欢谁` | **0** ❌ |
| 这个主角最后去哪了 | `这个 个主 主角 角最 最后 后去 去哪 哪了` | **0** ❌ |

短问句能用，只是因为剥完疑问词刚好剩下一个完整人名 —— 属**碰巧**，不是设计。

**修法**：不再赌一把，而是生成**候选词阶梯**逐级降级。

```
L0      = 整句（短问句走这级就命中，行为不变）
L1..N   = 2~4 字滑窗，按「位置优先→ 同位置长度降序」排序
MAX_TERMS = 12 封顶；凑够 4 章立刻停
```

滑窗**按段**切（剥词后标点会变成空格），否则会造出`修苏` 这种原文里
不存在的相邻对 —— 它**看起来**是个正常的二字候选，于是**静默失效**，最难查。

### 顺带发现：噪音比0 召回更糟

第一版只有阶梯、没有过滤，真书一跑召回了 4 章 `这个主`：

| 问句 | 首个命中词（过滤前 → 后） |
|---|---|
| 苏沐橙喜欢谁 | `这个主` → **`苏沐橙`** |
| 叶修怎么退役 | `修是` → **`叶修是`** |
| 林动为什么能修炼 | `老来` → **`林动`** |
| 萧炎用什么功法 | `用的什么` → **`萧炎`** |

这些词**在原文里真的出现过**，黑名单挡不住（`这个主` ≠ `这个`）。
0 召回用户会换个词再试，**答非所问用户只会以为程序坏了**。

两道过滤：整词黑名单（这个/最后/喜欢…）+ **首字**虚字过滤（这个主/个主）。
只卡首字不卡尾字 ——「元尊」「萧炎」第二个字完全可能是常用字，卡尾字会误伤真人名。

### 失败提示不能指错方向

之前召不回一律提示"请确认这本书已建立全文索引"。而用户明明建了索引，
于是反复重建、反复失败。**把用户往错误方向引比报错更糟** ——
那会让人以为是自己操作错了。现在区分「没索引」与「召不回」，
后者给出换词建议。

## 3. 绿色版现在带 AI 服务源码了

之前绿色版只有 `exe + runtime`，AI 面板却让你"在 qingdu-ai 目录执行"，
而那个目录不存在。解压后现在是：

```
QingduReader\
├── QingduReader.exe
├── app\   runtime\
└── qingdu-ai\        ← 新增：AI 服务源码（14 个文件）
```

**但包里带了源码、不带 `.venv`。** 因为 venv 内部全是写死的本机绝对路径
（`pyvenv.cfg` 的 `home`、`Scripts\*.exe` 的启动器、`site-packages\*.pth`），
拷到别人机器上会去找一个不存在的 Python，表现为"我明明装过了"但依然
`ModuleNotFoundError` —— **比干脆不装更难排查**。所以 venv 只能每台机器各建一次。

绿色版用户的首次启动：

```powershell
cd QingduReader\qingdu-ai
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -e ".[dev]"
$env:QINGDU_LLM_API_KEY = "sk-你的key"; $env:QINGDU_LLM_MODEL = "deepseek-chat"
.\.venv\Scripts\python.exe -m qingdu_ai
```

以后每次只跑最后一行。**第 2 行和第 5 行必须用 `.venv` 里的解释器。**

> 不装 AI 服务也能正常读书 —— 阅读器本体是纯 Java、零外部依赖的。

## 提问技巧：问句里带上书里出现过的专有名词

这一版是**关键词检索**、不是语义检索。四本真书 36 次真实检索的结果：

| 你这样问 | 效果 |
|---|---|
| 「苏沐橙喜欢谁」 | ✅ 命中 `苏沐橙` |
| 「叶修怎么退役」 | ✅ 命中 `叶修` |
| 「这个主角最后去哪了」 | ⚠️ 只能召回含"主角"的章节 —— 语义问题留到 v0.5 |
| 在《武动乾坤》里问「叶修是谁」 | ✅ 正确地召不回 —— 这书里没有叶修 |

**换成书里的人名、地名、门派名（越短越好）**，命中率最高。
界面上提示"没有召回到相关原文片段"时，多半不是程序坏了，
而是这个问题里没有书里出现过的词。
